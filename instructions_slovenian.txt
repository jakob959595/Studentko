PROJEKTNI NAČRT: ŠTUDENTKO (studentko) - verzija 3 (TypeScript)

================================================================================





1. IME IN VIZIJA PROJEKTA

--------------------------------------------------------------------------------

- Ime aplikacije: Študentko (studentko)

- Glavni namen: Osebni študentski asistent, ki združuje urnik, študijske

  obveznosti in rezultate (finance po želji). Uporaben za več študentov,

  ne samo zame.

- Način razvoja: Side projekt brez fiksnega roka, glavni cilj je učenje.

  Modularno po fazah, od znotraj navzven (najprej podatki in logika, šele

  nato vmesnik). Kodo pišem sam. AI uporabljam kot mentorja (razlaga

  konceptov, pregled moje kode, iskanje napak), ne za pisanje celih blokov.





2. FAZE

--------------------------------------------------------------------------------

[FAZA 0] Temelji

  * TypeScript osnove: tipi (types, interfaces), unije (union types),

    asyn/await, obravnava napak (try/catch), moduli.

  * Postavitev projekta (npm init, tsconfig.json, struktura map, git).

  * SQLite + Drizzle ORM (migracije, prvi model: users, obveznosti).

  * CILJ: preprost program v terminalu, ki doda in izpiše obveznosti iz baze.



[FAZA 1] Jedro: urnik in obveznosti (MVP)

  1.1 Podatkovni model: users, predmeti, obveznosti (vaje, kolokviji, izpiti

      z roki in statusom), dogodki urnika. Vsak uporabnik ima svoje podatke.

  1.2 Uvoz urnika iz .ics (vključno s ponavljajočimi se dogodki, RRULE).

  1.3 Telegram bot: ukazi (/start, /danes, /teden, /dodaj, /opravljeno).

  1.4 Scheduler v ozadju:

      - Vsako jutro (ali zvečer): dnevni urnik, vreme, prihajajoči roki.

        Opozorila za neopravljene vaje se vsak dan stopnjujejo, dokler

        jih ne odkljukaš.

      - Ob sobotah/nedeljah: povzetek kolokvijev in rokov za oddajo vaj

        za prihajajoči teden.

  1.5 Testi za logiko (roki, stopnjevanje opozoril, ponavljanje dogodkov).



[FAZA 2] Deploy in DevOps

  * Docker (Dockerfile), zagon na strežniku (VPS ali Fly.io), da bot teče

    24/7 in ga lahko uporabljajo tudi sošolci.

  * Nastavitve prek .env, redne varnostne kopije baze, logiranje.

  * GitHub Actions: samodejni typecheck, build in testi ob vsakem pushu.



[FAZA 3] Študijska statistika in ocene

  * Beleženje točk pri vajah, kolokvijih in izpitih po predmetih.

  * Izračun povprečij, manjkajočih točk do pogoja/ocene.

  * Prikaz napredka (najprej v botu, grafi kasneje v spletnem vmesniku).



[FAZA 4] Spletni vmesnik

  * REST API (Hono ali Fastify nad obstoječo logiko), registracija in prijava.

  * Frontend: React + TypeScript ali SvelteKit, odziven (MacBook, iPad,

    iPhone). Deljenje tipov med backendom in frontendom.

  * Urnik, obveznosti in statistika na enem mestu.



[FAZA 5] Opcijsko

  * Študentske finance (prihodki, odhodki po kategorijah, mesečna bilanca),

    samo če bom imel še voljo.

  * Druge ideje, ki se pokažejo med razvojem.





3. TEHNOLOŠKI SKLAD (TECH STACK)

--------------------------------------------------------------------------------

* Backend & logika: TypeScript (Node.js)

  -> Znana JS osnova + strogi tipi, en jezik za celoten projekt (kasneje

     tudi za frontend).



* Podatkovna baza: SQLite (kasneje po želji PostgreSQL)

  -> Knjižnica: better-sqlite3 + Drizzle ORM (zelo čiste migracije in tipi).



* Obvestila: Telegram bot (knjižnica grammY)

  -> Sodobna knjižnica napisana v TypeScriptu z odličnim avtodopolnjevanjem.



* Urnik: uvoz .ics (knjižnici node-ical ali ical.js + rrule za ponavljanja).



* Scheduler: node-cron (opravila v ozadju ob določenih urah).



* Vreme: Open-Meteo API (brezplačen, brez API ključa).



* Testiranje: Vitest (hiter test runner z vgrajeno podporo za TypeScript).



* DevOps: Docker, GitHub Actions, VPS ali Fly.io.



* Frontend (kasneje): React + TypeScript ali SvelteKit.
